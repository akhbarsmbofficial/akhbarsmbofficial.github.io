# موقع Akhbarsmb Official: دليل النشر والإدارة

الملفات في هذا المجلد:

- `index.html`: الموقع نفسه، لا تحتاج تعديله.
- `news.json`: الأخبار والإعلانات. هذا هو الملف الوحيد الذي ستعدّله.
- `banner.jpg`: صورة الشعار.

## 1) النشر مجاناً على GitHub Pages (مرة واحدة)

1. أنشئ حساباً على github.com، وفعّل التحقق بخطوتين من إعدادات الحساب (مهم، فهو الحماية الوحيدة للوحتك).
2. أنشئ مستودعاً جديداً (New repository) باسم مثل `akhbarsmb`.
3. اضغط Add file ثم Upload files، وارفع الملفات الثلاثة، ثم Commit.
4. من إعدادات المستودع (Settings) افتح قسم Pages، واختر Deploy from a branch، ثم الفرع `main`، ثم Save.
5. بعد دقائق يظهر رابط موقعك في نفس الصفحة.

بديل: موقع Netlify يقبل سحب المجلد كاملاً وإفلاته (Netlify Drop) وينشره فوراً.

## 2) إضافة خبر

1. افتح `news.json` في المستودع واضغط أيقونة القلم (Edit).
2. انسخ كتلة خبر كاملة والصقها فوق الخبر الأول، وغيّر `id` إلى رقم جديد لم يُستخدم، ثم عدّل النص.
3. اضغط Commit changes. يتحدّث الموقع خلال دقيقة أو اثنتين.

```json
{
 "id": 12,
 "cat": "لبنان",
 "breaking": true,
 "time": "قبل 5 دقائق",
 "title": "عنوان الخبر",
 "summary": "ملخص الخبر في سطرين.",
 "body": ["الفقرة الأولى.", "الفقرة الثانية."],
 "img": "صورة-الخبر.jpg"
}
```

- أول خبر في القائمة يظهر كخبر رئيسي.
- `breaking: true` يضعه في شريط "عاجل".
- `cat` أحد: لبنان، سياسة، اقتصاد، رياضة، تكنولوجيا، منوعات.
- `img` اختياري. ارفع الصورة إلى المستودع بجانب `index.html`، واكتب اسم ملفها.
- انتبه للفواصل والأقواس: كل خبر يُفصل عن الذي بعده بفاصلة، والخبر الأخير بلا فاصلة.

## 3) الإعلانات المدفوعة

في آخر `news.json` قسم `ads` بأربع مساحات: `top` و`side` و`feed` و`bottom`. لوضع إعلان، ارفع صورته إلى المستودع واكتب:

```json
"top": { "img": "اعلان.jpg", "href": "https://رابط-المعلن", "alt": "اسم المعلن" }
```

مقاس الشريط تقريباً 970×100، والمربع الجانبي 300×250. اتركها `null` لتظهر عبارة "أعلن معنا".

## 4) الطقس

يعمل تلقائياً على الاستضافة: يجلب الموقع بيانات بيروت وطرابلس وزحلة من Open-Meteo عند كل فتح للصفحة وكل 30 دقيقة، دون أي تدخل منك.

## الأمان

لا يستطيع أحد تعديل الموقع إلا من يدخل حساب GitHub الخاص بك. حافظ على كلمة المرور والتحقق بخطوتين، ولا تشارك صلاحية المستودع إلا مع من تثق به.
